How guests connect

  1. Open the normal camera app (iPhone or Android — no extra app needed).
  2. Point it at the code on the sign.
  3. Tap the "Join network" prompt. Done — no typing.

Why a QR sign beats a sticky note

Most host messages in the first hour of a stay are about WiFi. A framed sign with a scannable code removes the typing, the typos and the "which network is it?" question. It also looks like you run a professional place — because you do.

Put it where guests naturally stop when they arrive: the kitchen counter, the entryway console, or the bedside table. If you have a second building or a guest suite with its own router, print one for each.

What to put on the sign

  • Network name exactly as it appears on the phone, including capitals and underscores.
  • Password written out as well as in the code — some guests prefer to type.
  • A one-line hint such as "Scan with your phone camera" — older guests don't always know QR codes work from the camera app.

Questions

Is my WiFi password uploaded anywhere?

No. The code is generated inside your browser. Nothing you type is sent to our server or stored anywhere except your own device.

What size should I print it?

The sign is laid out for A4 or US Letter. Print at 100% scale, put it in a standard frame, and place it where guests arrive.

Does the code still work if I change my password?

The code contains the password, so reprint it after a change. Come back here, type the new password, print again — 30 seconds.

Which phones can scan it?

Any iPhone since iOS 11 and any Android phone from the last several years scans WiFi codes from the built-in camera app. Older phones may need a free QR app.
